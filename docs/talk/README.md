# 分享材料

| 文件 | 内容 |
|---|---|
| `讲稿.md` | 逐页讲稿：按幻灯片页码编排的口语稿、演示步骤、Q&A 预案、命令速查与分享前核对清单 |
| `slides/deck.json` | 幻灯片索引：标题、页序、分节 |
| `slides/slides/*.html` | 每页幻灯片源文件，讲者备注在每页最后的 `<aside>` 里 |

讲稿和幻灯片的编辑版本在 Claude 里，这里是 2026-10-16 的快照，内容以那边为准；改完记得重新同步到这里。

幻灯片源文件依赖 Claude Slides 的运行时渲染，不能直接用浏览器打开。附录两页截图引用的是 `/_blob/…` 资源，没有随源文件导出。

版本口径：全场讲 Pi v1.2.0（源码走读对应 main 提交 3daa202）；只有官方 Durable 实验版的演示在 v1.1.0 上跑。本仓库 `package.json` 锁的是 1.1.0，见根目录 README 自检清单。
