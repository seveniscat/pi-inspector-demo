# 分享材料

| 文件 | 内容 |
|---|---|
| `幻灯片.html` | **浏览器直接打开的幻灯片**：← → 翻页，N 讲者备注，F 全屏，G 跳页；地址栏 `#7` 定位到第 7 页；打印可导出 PDF |
| `讲稿.html` | 讲稿的网页版，自动跟随系统深浅色 |
| `讲稿.md` | 逐页讲稿：按幻灯片页码编排的口语稿、演示步骤、Q&A 预案、命令速查与分享前核对清单 |
| `slides/deck.json` | 幻灯片索引：标题、页序、分节 |
| `slides/slides/*.html` | 每页幻灯片源文件，讲者备注在每页最后的 `<aside>` 里 |
| `build-html.py` | 由 `slides/` 生成 `幻灯片.html`，只用 Python 标准库 |

讲稿和幻灯片的编辑版本在 Claude 里，这里是 2026-10-16 的快照，内容以那边为准；改完记得重新同步到这里。

`slides/` 下的源文件依赖 Claude 幻灯片的运行时，不能直接打开，看 `幻灯片.html` 即可。同步新的源文件后重新生成：

```bash
python3 docs/talk/build-html.py
```

字体走 Google Fonts，离线时回退到系统字体。附录两页截图引用的是 `/_blob/…` 资源，没有随源文件导出，`幻灯片.html` 里显示为占位框。

版本口径：全场讲 Pi v1.2.0（源码走读对应 main 提交 3daa202）；只有官方 Durable 实验版的演示在 v1.1.0 上跑。本仓库 `package.json` 锁的是 1.1.0，见 docs/reference.md 自检清单。
