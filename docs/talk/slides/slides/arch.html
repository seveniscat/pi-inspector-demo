01 · WHAT

分层架构：按真实依赖画

pi-coding-agent

CLI、TUI、RPC、SDK；会话、内置工具、skills、扩展

pi-agent-core · pi-tui · pi-mcp · pi-codemode

coding-agent 的直接依赖：agent loop、终端 UI、MCP 客户端、沙箱脚本

pi-ai

统一的多 provider LLM API，依赖 pi-telemetry

coding-agent 直接依赖以上全部；中间一层只有 agent-core 依赖 pi-ai，tui、mcp、codemode 不依赖其他内部包

pi-durable（实验性）

与 agent-core 平行的另一套 harness：先提交再展示，崩溃后从 checkpoint 继续。

依赖 pi-ai、pi-codemode、chord；不在 coding-agent 的依赖链上。

chord

可热更新插件、复制状态、JSON 链路 RPC。1.2.0 起 coding-agent 不再依赖它。

来源：main 分支（v1.2.0）各包 package.json 的 dependencies；README「Packages」

这张图按 main 分支（v1.2.0）各包 package.json 的 dependencies 画。主干是 pi-coding-agent → pi-agent-core → pi-ai；pi-tui、pi-mcp、pi-codemode 是 coding-agent 的直接依赖。pi-mcp 是独立的 MCP 客户端，pi-codemode 是只能调用注入工具的沙箱 JavaScript 执行；这两个包不在 README 的 Packages 表里，但在依赖链上。pi-durable 是与 pi-agent-core 平行的另一套 harness，不是 coding-agent 的底层。1.2.0 移除了 coding-agent 对 chord 的依赖，chord 现在由 pi-durable 和 pi-env 使用。pi-agent-core 在 1.1.0 移除了实验性 harness，现在只包含 Agent 类、agent loop、proxy stream 及其类型；coding-agent 从它只取 Agent 和类型，会话、压缩、skills 都是 coding-agent 自己实现的。仓库里另有 env（Pi Durable 的远程执行环境）和 evals（私有包），图中不画。
