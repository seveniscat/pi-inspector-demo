【切到编辑器与终端】提前准备一个已有几轮对话、并执行过一次 /compact 的会话，现场不用等模型。 1. 打开 ~/.pi/agent/sessions/--<path>--/<timestamp>_<session-id>.jsonl。第 1 行是 type 为 session 的文件头（version 3），只有元数据，不在树里：它的 id 是会话 ID，没有 parentId。之后每行一条记录，都有 id 和 parentId，靠 parentId 连成树。 2. 在 Pi 里执行 /tree，选一条早先的用户消息，它的文本会回到编辑器，改写后提交就长出新分支，旧分支原样保留。源码里（agent-session.ts 的 navigateTree）选中用户消息后，leaf 移到它的父节点；所以不生成摘要时，新消息的 parentId 与被选消息的 parentId 相同，也就是分叉点。选择生成摘要时，分叉点上先插入一条 branch_summary 记录，新消息挂在它下面。演示时选不生成摘要，画面更直观。 3. 找到 type 为 compaction 的那一行，指出 summary 和 firstKeptEntryId（保留起点）；原始记录仍在文件里。 字段名来自 docs/session-format.md。看完回到 slides → 进程挂了能接上吗。
