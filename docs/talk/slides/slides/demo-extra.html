04 · DEMO

Demo 里还会出现的三个能力

pi-ai

多模型

一套统一 API 接多家 provider。会话中用 /model 或 Ctrl+P 切换，历史在发送前按目标模型转换。

SKILL.md

Skills

系统提示只带每个 skill 的名称和描述，任务需要时模型再读取完整说明。遵循 Agent Skills 规范。

/compact

压缩

接近上下文上限时自动压缩：旧消息变成摘要，默认保留最近约 2 万 token；原始条目留在会话文件里。

稍后的 demo 里会看到：模型读取 SKILL.md、换一家厂商继续、触发压缩。

来源：docs/models.md；docs/skills.md；docs/compaction.md；pi-ai src/api/transform-messages.ts

这三个能力不单独展开，在 demo 里看它们出现。多模型切换的细节：pi-ai 发请求前会按目标模型转换历史，同一模型保留带签名的 thinking 块，换了模型就把 thinking 转成普通文本、丢弃加密的 redacted thinking，并规范化工具调用 ID。压缩保留的近期部分由 compaction.keepRecentTokens 控制，默认 20000。
