03 · LOOP

一条 prompt 的事件流：turn 是基本单位

agent_start

turn_start

message_* (user)

message_start / update... / end (assistant)

tool_execution_start / update / end

message_* (toolResult)

turn_end

turn_start // 工具结果交回 LLM

message_* (assistant)

turn_end

agent_end

turn = 一次 LLM 调用，加上它触发的所有工具执行。

助手不再请求工具、队列也为空，loop 才结束。

进度全部以事件流出，界面只需订阅。

来源：packages/agent/README.md「Event Flow」

先问：一条带工具调用的 prompt 会产生几个 turn？答案是两个：第一个 turn 里模型请求工具并执行，第二个 turn 把工具结果交回模型。重点是 loop 与 UI 解耦：进度全部以事件流出，这就是一个内核能服务四种宿主的原因。下一页把这条事件流画成控制流。
