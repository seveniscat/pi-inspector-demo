【第 1–6 步：切到 Inspector】切换前确认：服务已启动（npm run start:new）、页面已打开、两家厂商的凭据都可用、真实数据已导入。 1 一句话进去：输入"分析一下最近 7 天的舆情"。展开 System Prompt（skill 只有描述，AGENTS.md 在内）；时间线先 read SKILL.md，再 dataset_info，按监测词拆题写 plan.md，进度条出现。 2 插话：第 1 个话题中插话"只看抖音和小红书"，下一次查询参数带上平台；再发"最后给运营 3 条建议"，作为 follow-up 排到最后。 3 护栏：插话"直接用 bash 统计一下 ../data 里的评论条数"，出现"护栏拦截"，模型改用工具。软约束（AGENTS.md）和硬约束（tool_call 钩子）。 4 定点崩溃：第 2 个话题开始时点"定点崩溃"，下一次查询写进缓存后进程被杀；终端 npm start；恢复卡片、会话树恢复点、上下文修补、重查"缓存命中"。 5 换模型 + 压缩：点"从断点继续"前切到模型 B；顶部花费按模型拆开；压缩卡片下的前后对比条；结论在话题笔记文件里，压缩不丢。 6 报告与引用：点"报告"，引用核验 N/N，点 ID 看原评论（作者已脱敏）。 第 4 步的恢复是我们写的 resume 扩展，不是 Pi Durable，讲的时候点明。现场跑不起来：npm run replay -- runs/final --speed 3 回放彩排存档；再不行翻到附录最后两页截图。 【第 7 步：切到终端，v1.1.0 checkout】官方 Durable 实验版只存在于 v1.1.0，1.2.0 已移除 src/experimental，所以在单独的 v1.1.0 checkout 里运行（浅克隆需要先 git fetch --depth 1 origin tag v1.1.0）。 $ git checkout v1.1.0 && npm install && npm run build $ node --import ./packages/coding-agent/src/experimental/source-resolver.ts packages/coding-agent/src/experimental/durable/main.ts 工具调用进行中执行 kill -9 <pid>，再在同一条命令后加 --continue 重启。 看点：不装扩展，恢复由 Harness 完成；中断的调用重启后拿到 interrupted 结果，这一轮正常收尾；每个会话一个 SQLite 文件，流式输出、工具结果、队列都随时提交。凭据与 pi 共用，先用 pi 登录。kill -9 留下的锁 10 秒后才过期，重启时会先等这 10 秒，提前告诉听众不是卡住了。现场不稳定就播录屏。 看完回到 slides → 我们可以从哪里开始探索。
