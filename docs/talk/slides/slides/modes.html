01 · WHAT

同一个内核，四种用法

interactive

交互式 TUI

日常使用。1.0.0 起默认全屏，可改回常规滚动模式。

print / JSON

脚本与自动化

非交互运行，输出可被脚本和流水线消费。

RPC

被外部进程控制

宿主程序通过 RPC 驱动 Pi，适合嵌进自己的界面。

SDK

TypeScript SDK

把 agent 当库来用，自己做应用。官方举的真实集成例子是 OpenClaw。

四种用法共用同一个 agent loop：loop 只产出事件，界面和传输方式都在它之外。

来源：earendil-works/pi README

重点不是四种模式本身，而是它说明 agent loop 与 UI、传输方式是解耦的。后面讲 Loop 时会看到这一点在源码里的落点：事件流。
