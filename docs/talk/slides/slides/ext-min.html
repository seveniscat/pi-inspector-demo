03 · EXTENSIONS

最小的扩展：导出一个工厂函数

import type { ExtensionAPI } from "@earendil-works/pi-coding-agent";

export default function (pi: ExtensionAPI) {

pi.registerCommand("hello", {

description: "Show a greeting",

handler: async (name, ctx) => {

ctx.ui.notify(`Hello, ${name || "world"}!`, "info");

},

});

}

放进 ~/.pi/agent/extensions/，或用 pi --extension ./hello.ts 直接加载。

用 jiti 加载，本地 TypeScript 不需要单独编译。

工厂里不要起进程、定时器，放到 session_start 里。

来源：packages/coding-agent/docs/extensions.md「Create and load an extension」

先给一个最小例子：能力通过一个默认导出的工厂函数注册。工厂可以是异步的，Pi 会等它完成再继续启动。例子里用的是 registerCommand；registerTool 的形态类似，需要名称、给模型看的描述、TypeBox 参数 schema 和 execute()。
