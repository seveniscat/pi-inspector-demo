03 · EXTENSIONS

扩展靠两样东西改变行为：钩子与工具暴露

事件钩子 pi.on()

tool_call

改写入参或阻止执行

before_agent_start

调整提示词片段与工具

tool_result

多个 handler 依次叠加改写

message_end

替换已定稿的消息

context

改写发给模型的对话

工具暴露 exposure

direct

默认，声明给模型并可调用

model-only

只给模型看，不可被其他工具调用

codemode

供 codemode 脚本调用

deferred

tool_search 找到后再激活

hidden

已注册但不可达

来源：packages/coding-agent/docs/extensions.md「Events and concurrency」「Tool exposure」

Pi 没有内置的功能，就是靠这两个机制从外面长出来的。tool_call 能阻止执行，是做权限确认、路径保护的入口；exposure 决定模型能不能直接看到某个工具。MCP 工具默认就是 codemode 暴露，不声明给模型，所以接再多 MCP server 也不会撑大工具声明。完整事件与返回类型见 src/core/extensions/types.ts 的导出声明。1.2.0 起，before_agent_start 也会对 pi.sendMessage(…, { triggerTurn: true }) 启动的 run 触发，只想处理用户输入的 handler 要检查 event.messageType。
