顺着箭头讲：prompt 进来，先整理上下文（transformContext 可裁剪、注入，convertToLlm 只留下 user、assistant、toolResult 三种角色），LLM 流式返回。有工具调用：参数校验后过 beforeToolCall（可拦截），工具默认并行执行，afterToolCall 可改写结果；结果写回后 turn 结束，源码在每个 turn_end 之后轮询 steering 队列，有就注入，然后开新 turn 让 LLM 读工具结果。没有工具调用：turn_end 后同样先查 steering，没有 steering 再查 followUp，有消息就注入并开新 turn，都没有才 agent_end。followUp 只在 agent 本要停下时检查，这是两者的本质区别。
