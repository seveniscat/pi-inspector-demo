03 · EXTENSIONS

社区 packages：能力在核心之外生长

@gotgenes/pi-permission-system

Pi 的权限控制

@gotgenes/pi-subagents

进程内的自主 sub-agent 核心

@gotgenes/pi-github-tools

确定性的 GitHub CI、release、issue 工具

@gotgenes/pi-colgrep

把语义代码搜索作为 agent 工具

pi install npm:@gotgenes/pi-subagents

pi install git:github.com/user/repo

这些是社区包，不是官方。扩展与 Pi 同权限，安装前先审查源码。

来源：github.com/gotgenes/pi-packages；docs/packages.md

开头说 Pi 不内置 sub-agents 和权限系统，社区已经用 package 补上了。这正是 package 机制的意义：核心保持小，能力在外面长。pi install 支持 npm: 和 git: 两种来源，都可以固定版本或 ref。
