APPENDIX

上手：两分钟跑起来

curl -fsSL https://pi.dev/install.sh | sh

# 或者

npm install -g --ignore-scripts @earendil-works/pi-coding-agent

cd /path/to/project && pi

/login # 连接订阅或 API key

要求 Node.js 22.19 或更新版本，官方安装脚本在需要时可以帮你装。

安装脚本会固定全部依赖，用 pi update 升级；npm 安装不固定传递依赖。

正常安装不需要依赖的生命周期脚本，官方建议加 --ignore-scripts。

来源：README「Getting started」与「Supply-chain hardening」；Windows 用 install.ps1
