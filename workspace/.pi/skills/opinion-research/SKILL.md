# 舆情研究链路

输入可能只有一句话（如"关于英雄令的舆情"）。按下面 7 步走，最终产出 `report/report.md`。

## 可续做（幂等）——任何一步开始前先检查

- `research/plan.md` 存在 → **已经界定过范围、拆过题**，直接按它继续，不要重做第 0～3 步。
- `research/` 下已有某个 `qN-*.md` → 这个问题已完成，跳过。
- 每写完一份文件（plan.md、每份证据笔记、报告）**立刻**调用 `checkpoint`：`task` 填研究对象，`done` 传已完成项的完整列表，`total` 填 5（Q1～Q4 + 报告）。
- 工具结果出现 `[interrupted]`：那一步执行到一半进程被杀了，先 `ls` / `read` 核实文件状态再决定是否重做。
- 查询工具带缓存，重复同样的查询是安全的。

## 第 0 步：解析需求（不调工具）

从用户输入里提取：研究对象、时间范围、平台、关注点。没说的按默认：时间 = 数据中最近 7 天；平台 = 全部；关注点 = 综合研判。

## 第 1 步：界定研究对象

1. `dataset_info`：看数据覆盖的时间范围、平台、抓取用过的搜索词。
2. `social_search` 用对象名粗搜（按评论数排序），再用 `get_post` 抽读 2～3 个评论最多的帖子。
3. 回答：这个对象具体是什么？属于哪个品牌 / 公司？有哪些别名 / 简称 / 相关词（参考 dataset_info 里的"来自搜索"）？有没有**同名但无关**的内容需要排除（看相关性不是「相关」的帖子）？
4. 写 `research/plan.md` 的「研究范围」：对象说明、查询词表（主词、别名、排除词）、时间范围、平台、样本量。

## 第 2 步：摸底

- `social_trend` 按天：找新评论突增或消极占比明显升高的日子（拐点）。
- `social_trend` 按平台：讨论主要集中在哪个平台。

## 第 3 步：拆题

在 `plan.md` 写 4 个问题，每个问题写 1～2 句准备怎么查（哪些关键词、平台、日期）：

- **Q1 声量与情绪**：整体走势、平台分布、拐点出现在哪天以及原因
- **Q2 讨论焦点**：大家在聊什么，正面和负面的主要观点，各给高赞评论作证据
- **Q3 风险与负面**：消极评论集中在哪些帖子 / 话题；有没有正在发酵的问题；按时间梳理首发 → 扩散 → 回应（如有）
- **Q4 关键传播节点**：哪些帖子 / 作者带动了讨论（评论最多、消极最多）；不同平台的差异

写完 plan.md 调用 `checkpoint`，`done` 传 `[]`。

## 第 4 步：逐题取证（一次只做一个问题）

1. `social_search` / `search_comments` / `social_trend` 按计划查；必要时换关键词、按时间或消极排序、翻页
2. 需要上下文时用 `get_post` 读帖子和高赞评论（每题 **不超过 4 次**，控制上下文）
3. 写 `research/qN-<简短主题>.md`（格式见下）
4. 调用 `checkpoint`，`done` 加上 `QN`

## 第 5 步：写报告

读取 plan.md 和全部证据笔记，写 `report/report.md`（格式见下）。完成后 `checkpoint`，`done` 加上 `报告`，`note` 写"报告已生成"。

## 第 6 步：自检

逐条检查报告：每个帖子 ID / 评论 ID 都能在证据笔记里找到；数字（帖子数、评论数、占比）都来自工具结果。有问题就改报告，最后用一句话说明自检结果。

## 判断规则

- **相关性**：数据自带相关性标签（如「相关」）。默认只用相关的帖子下结论（social_search 传 `relevance`）；其他标签的帖子先抽看确认，在研究范围里说明排除了多少。
- **时间粒度**：部分评论只有日期没有时分，时间线精确到天即可，不要编造具体时刻。
- **代表性**：一条高赞评论可能比十条零赞评论更有代表性；结论里说明依据的是数量还是点赞 / 评论量。
- **情绪标签是数据自带的**，可能有误判；关键结论要用评论原文佐证，不要只报比例。
- **区分事实和传言**：只有个别评论提到、没有其他佐证的说法，标"待核实"。
- **证据可追溯**：每条结论至少引用 2 个帖子或评论 ID；不允许编造 ID 或引文。
- **脱敏**：报告不写评论用户的昵称；帖子作者是官方 / 媒体 / 大号的可以写。

## 证据笔记格式

```markdown
# QN <问题>
## 结论
- 结论 1（证据：[帖子ID]、[评论ID]）
## 关键证据
- [ID] 平台 日期 评论数/点赞：一句话摘录
## 待核实 / 存疑
- 没有就写"无"
```

## 报告格式

```markdown
# <研究对象> 舆情分析报告（<起止日期>）
> 数据来源与样本：平台、帖子数、评论数、时间范围、排除了哪些无关内容

## 一句话结论
## 1. 声量与情绪（附按天走势表）
## 2. 讨论焦点
## 3. 风险与负面（如有事件，附时间线表格：时间 | 事件 | 证据）
## 4. 关键传播节点与平台差异
## 5. 建议（3 条，具体到动作和负责方）
## 附：证据索引
```
